# The exact first primitive prefix of the tangent-moment sequence

Status: short proved refinement discovered during the independent audit
of cyclotomic-mobius-integrality.md. The finite-field tangent congruence
is an input from that independently checked note. Historical novelty is
unresolved and not claimed.

For a fixed odd integer \(s\ge3\), put
\[
A_e=T_{2e+1}\binom{s+2e}{s-1}=\nu_{s,4}(t^e),\qquad
Q(s)=\max_{p\mid s}p^{v_p(s)}.
\]
Thus \(A_0=s\). Then the first prefix having gcd one ends at exactly
\[
\boxed{
\min\{E\ge0:\gcd(A_0,A_1,\ldots,A_E)=1\}
=\frac{Q(s)-1}{2}.}
\tag{1}
\]

In particular, the previous bound \((s-1)/2\) is sharp if and only if
\(s\) is a power of an odd prime.

**Proof.** Fix \(p\mid s\), write \(P=p^{v_p(s)}\), and \(s=Pu\) with
\(p\nmid u\). If \(0\le e<(P-1)/2\), the lower
\(v_p(s)\) digits of \(s-1\) are all \(p-1\), while the corresponding
digits of \(s+2e\) represent \(2e<P-1\). At least one upper digit is
strictly below the corresponding lower digit in the binomial
\(\binom{s+2e}{s-1}\). Lucas's theorem therefore gives \(p\mid A_e\).

At the first possible index \(e=(P-1)/2\), symmetry of the binomial and
Lucas's theorem give
\[
\binom{s+P-1}{s-1}
=\binom{s+P-1}{P}\equiv u\pmod p.
\]
The tangent congruence
\[
T_P\equiv(-1)^{v_p(s)(p-1)/2}\pmod p
\]
is a unit. Thus this particular \(A_e\) is not divisible by \(p\).
We have proved the exact first index at which each prime divisor of
\(s=A_0\) ceases to divide the entire prefix.

No other prime can divide a prefix gcd because that gcd divides \(A_0\).
Taking the largest of those first indices proves (1). The equality
\(Q(s)=s\) holds precisely when \(s\) is a prime power. QED.

For example, \(s=15\) needs only \(e=0,1,2\), because \(Q(15)=5\);
the original bound would allow seven. For \(s=9\), all the moments
with \(e<4\) remain divisible by three, and \(e=4\) removes it, so the
original bound is attained.

The exact checker check_cyclotomic_independent_review.py verifies both
the threshold for each prime and the first gcd-one index for every odd
\(s\le151\), using tangent numbers independently generated by repeated
application of \((1+y^2)d/dy\).

This concerns fixed common integer divisors of the moment sequence.
It gives no determinant denominator bound and does not exclude
cancellations depending on the determinant index.
