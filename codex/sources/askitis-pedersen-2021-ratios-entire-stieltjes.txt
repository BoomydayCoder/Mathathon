functions of finite genus having only real and non-positive zeros.
     A completely monotonic function ϕ is a C ∞ -function defined on (0, ∞)
such that (−1)n ϕ(n) (x) > 0 for all n = 0, 1, . . . and all x > 0. These func-
tions are characterised via Bernstein’s theorem as the Laplace transforms
of positive measures. A logarithmically completely monotonic function is
a positive function ϕ for which −(log ϕ)′ is completely monotonic. These
functions are also completely monotonic and can be characterised as those
completely monotonic functions for which any nth root is also completely
monotonic. For background on these functions see e.g. [11] and [12]. A func-
tion f defined on (0, ∞) is called a generalised Stieltjes function of order λ
if it admits the representation
                                  Z ∞

c ≥ 0. It is known, and easy to verify, that a function is a generalised
Stieltjes function of order λ if and only if it is the Laplace transform of
tλ−1 ϕ(t), where ϕ is completely monotonic.
