# R4: numerics for the "perceptron" model of empty ellipsoids

Files: `partA.py` (abstract Gaussian/Poisson model: LP and min-norm QP), `partB.py` (geometric Poisson model in R^n:
trace-LP, pivoting ascent, Klartag process), `analyze.py` -> `results_table.md`, raw data `data/*.jsonl` (one JSON record per
sample), `trunc_pred.txt` (Gordon threshold recomputed with the cutoff actually used), `data_aborted/` (two aborted launches
of N=200, see "Problems").  Every number below was produced by this code in this round.

## 0. Model and what was solved (definitions)
Part A.  Offsets sigma_i^0: Poisson process on (-inf, smax] with intensity (v_ref/4) e^{s/2} ds, v_ref = N,
smax = 2 log(2c) so that the mean number of constraints is cN (c = 300; sampled as smax + 2 log U).  g_i iid N(0, I_N).
LP: maximise t s.t. <theta,g_i> + sigma_i^0 - t >= 0, by constraint generation (working set = 4N smallest offsets, add violated
rows, re-solve with HiGHS; at the end ALL cN constraints are checked).  v* = v_ref e^{t*/2}.  Shifted offsets
sigma_i = sigma_i^0 - t* are the offsets relative to the ball of volume v*.
QP: min |theta|^2 s.t. <theta,g_i> >= t - sigma_i^0 for fixed t = 2 log(v/N): Lawson-Hanson "least distance programming"
(NNLS on E = [G_W^T ; b_W^T], f = e_{N+1}; theta = -r_{1..N}/r_{N+1}), again with constraint generation and a final check
of all constraints.
Part B.  Pairs +-x: volumes kappa_n|x|^n form a Poisson process of rate 1/2 on [0, V_max], directions uniform;
V_max = 3000 N.  Length unit = radius of the ball of volume N, so V/N = det(A)^(-1/2), v/N = (Tr A/n)^(-n/2).
Trace-LP: min Tr A s.t. x_i^T A x_i >= 1 (N free variables, orthonormal coordinates of Sym_n), constraint generation
(working set = 6N nearest points), final check of all points.
Cutoff control for B: (a) largest volume kappa|x|^n of an active point vs V_max; (b) Monte-Carlo estimate (2e4 uniform
samples of the ellipsoid) of vol(E \ sampled ball)/2 = expected number of pairs of the infinite Poisson process inside E that
were not sampled; if this is << 1 the LP optimum is, with that probability, the optimum for the infinite process
(the LP optimum of a relaxation that is feasible for the full problem is optimal).

## 1. Derivations checked while doing the numerics (model statements)
(D1) [computed, elementary]  For the Poisson offsets with intensity (v/4)e^{s/2} and Z ~ N(0,1):
  F(r) := sum_i E (sigma_i + r Z)_-^2 = (v/4) E int e^{s/2} (s + rZ)_-^2 ds = (v/4) E[e^{-rZ/2}] int_0^inf u^2 e^{-u/2} du
        = (v/4) * 16 * e^{r^2/8} = 4 v e^{r^2/8}.
  Number of i with sigma_i + r Z_i < 0:  (v/4) E int_{-inf}^{-rZ} e^{s/2} ds = (v/2) e^{r^2/8}.
  Gordon condition F(r) <= r^2 N  <=>  v <= N r^2 e^{-r^2/8}/4, maximal at r^2 = 8: v* = 2N/e; active count there
  (v*/2) e = N; V = v* e = 2N.  (Agrees with (C1), (C2) of the task statement.)
(D2) [correction to my own first guess; heuristic from the Gordon picture, confirmed numerically]  The law of the offsets of
  the ACTIVE constraints is not N(rho^2/2, rho^2).  Active <=> sigma + rho h < 0 with h ~ N(0,1): density
  prop. to e^{s/2} Phi(-s/rho).  Writing s = -rho h - u (u > 0): h is tilted to N(-rho/2, 1), u ~ Exp(mean 2), independent:
      sigma_active  =  N(rho^2/2, rho^2)  -  Exp(mean 2):   mean rho^2/2 - 2,  variance rho^2 + 4.
  At rho^2 = 8: mean 2, sd sqrt(12) = 3.46.  In volume terms (vol = v e^{sigma/2}): log(vol_active/v) has mean 1, sd 1.73.
  The upper tail (which decides the cutoff) is the Gaussian one: P(sigma_active > S) <= Phi(-(S-4)/2.83).

## 3. Part B(ii): Klartag's sticky process in the infinite Poisson model (exact simulation by lazy revelation)
First attempt (process on a ball-truncated Poisson sample, `klartag()` in partB.py): FAILED, two test runs (n=10,
V_max = 400N and 3000N) lost positive definiteness at t ~ 0.05 with 1-2 contacts.  Reason: with few contacts
A_t = I + projected W_t and the spectrum of W_t has radius 2 sqrt(n t) (1.4 at t = 0.05, n = 10): the ellipsoid grows needles
long before the bulk constraints react; a lattice has far points that stop the needles, a ball-truncated Poisson sample does not
(sample radius is only V_max^(1/n) ~ 2-3 inner radii).
Fix actually used (`partK.py`), an EXACT simulation of the process for the infinite Poisson process: keep snapshots
A_1..A_m; the dilated ellipsoids E'_i = {A_i x.x < 1+delta} are "revealed".  Every straight sub-step is first tested to stay
inside the latest snapshot (Loewner test A >= A_m/(1+delta), which is convex along the segment); if not, a new snapshot is taken
at the current form: Poisson(vol(E')/2) uniform points of E' are drawn and kept iff they lie outside all earlier E'_i and
outside the initial empty ball; if the step still leaves the fresh snapshot it is shortened by bisection.  Since the Poisson
process on the unrevealed region is independent of everything revealed, this is exact (up to the Euler/straight-segment
discretisation of the Brownian path, same as R2).  Start: largest empty ball (its volume v_1 ~ Exp(mean 2), one pair on the
boundary), dt = 1.25e-3/n in units r_1 = 1, delta ~ 4/n.  All frozen runs have exactly N contact pairs and
min q >= 1 - 1e-12 over all revealed points.
Result: see the table in section 2.  V_K/N is close to 1 (1.17, 1.09, 1.06, ... decreasing slowly with n), V(t)/k(t) ~ 1.05-1.15
along the whole path, i.e. the process ends at about HALF the volume of the trace-LP optimum (V_LP/N ~ 2), as predicted by
(C3).  The frozen ellipsoids are extremely eccentric (median lam_max/lam_min of several hundred, |B0|^2 = 6-12): the
process ends in a needle-like perfect configuration, not near the round LP optimum.

## 4. Part B(iii): no "extreme form" was reached in the Poisson model (finding)
Pivoting ascent: at a vertex with active set S (N independent contacts) write A^{-1} = sum_j lam_j x_j x_j^T; along the edge
B_j (B_j[x_i] = delta_ij) one has d/ds log det(A+sB_j)|_0 = lam_j and log det is concave along the edge, so the volume
increases along the whole edge iff lam_j < 0; rule: most negative lam_j/|B_j|_HS, move to the next contact.  No run stopped
at a vertex with all lam_j >= 0: every run ended by the time cap or because the entering point had volume > V_max/2 (sample
cutoff).  Along the path V/N increases slowly while lam_max/lam_min and the circumscribed-ball volume increase fast: the
ascent walks towards needles.  This is the expected behaviour: in a Poisson process (unlike a lattice, where Minkowski gives
V <= 2^n) empty origin-symmetric ellipsoids of arbitrarily large volume exist (thin needles), so sup V = infinity and "V_ext"
is only meaningful under an eccentricity constraint; this is regime (C4).  The numbers in the table are points of one greedy
path, NOT the maximum over ellipsoids of a given eccentricity, and the ascent was run on ball-truncated samples (the column
E[#unsampled pairs inside] tells how far it can be trusted).  A lazy-revelation version (as in partK.py) is the right tool.
