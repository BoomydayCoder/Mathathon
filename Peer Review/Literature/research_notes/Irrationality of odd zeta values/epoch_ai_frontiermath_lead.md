## Key question 2: The problem itself — statement, significance, contributors, evaluation criterion, posted AI results

### Takeaway
The problem asks for a linear recurrence with integer polynomial coefficients (order ≤ 25, degrees ≤ 25) and two integer initializations producing sequences a_n, b_n that certify irrationality of a target constant via a standard small-linear-forms criterion, checked numerically for n < 650. No contributor is named, no certificate for any target is reported, and no AI system is credited by Epoch with a solution in this format.

### Cited Findings
- Target constants, verbatim: "The prompt is posed independently for each of the following target constants: ζ(5), ζ(7), Catalan's constant, the Calegari-Dimitrov-Tang constant, and the Euler-Mascheroni constant γ." — [Problem page](https://epoch.ai/frontiermath/open-problems/apery-irrationality)
- Full prompt, verbatim (identical in the data file): "The goal of this problem is to prove the irrationality of a particular real number in a specific way. Let k be an integer with 1 ≤ k ≤ 25, and let P_0(x), ..., P_k(x) be polynomials with integer coefficients, each of degree at most 25, where P_k(n) ≠ 0 for n ≥ k. Let α = (α_0, ..., α_{k-1}) and β = (β_0, ..., β_{k-1}) be tuples of integers. Let (a_n) and (b_n) denote the sequences defined by the recurrence P_k(n)*u_n = P_{k-1}(n)*u_{n-1} + ... + P_0(n)*u_{n-k} for n ≥ k, when initialized with α and β respectively. Let L_n denote lcm(1,2,...,n) and let B_n = (L_n)^m*b_n, where m is a fixed positive integer. Let X be a real number. It is known that if the following hold, then X is irrational. 1. a_n is an integer for all n ≥ 0. 2. B_n is an integer for all n ≥ 0. 3. X ≠ b_n / a_n for all n ≥ 0. 4. |b_n - a_n*X| ≤ C*ρ^n*e^{-mn} for all n ≥ 0, where C and ρ are positive real numbers and ρ < 1. Your task is to find P_i, α, β, and m that establish the irrationality of ___ in this way." — [Problem page](https://epoch.ai/frontiermath/open-problems/apery-irrationality)
- Evaluation criterion, verbatim: "Your answer is verified numerically, as follows. Conditions 1-4 are checked for all 0 ≤ n < 650, with condition 4 checked using the fixed values C = 100 and ρ = 0.95. An answer that satisfies condition 4 only with a larger C or ρ is rejected; in particular, note that scaling α and β by a common factor scales C by that factor. In addition, every integer in the submission — each polynomial coefficient and each entry of α and β — may have at most 100 decimal digits. Conditions 1 and 2 are checked exactly, but condition 4 is checked in floating point against a value of X carrying 6000 decimal digits. This bounds how sharply the linear form may converge: if |b_n - a_n*X| falls below (|a_n| + |b_n|)*10^-5990 at some tested n, the computed value cannot be distinguished from zero and the answer is rejected. For a typical certificate, where |b_n - a_n*X| is of order 1/a_n, this accommodates m up to about 10. m > 21 is rejected immediately, since no certificate with this m could be checked given this precision." — [Problem page](https://epoch.ai/frontiermath/open-problems/apery-irrationality)
- Stated significance: notability tier "Breakthrough", which Epoch defines as "The median mathematician would want to know about this result, even if it was outside their area. It would be a candidate for one of the best results of the year in all of mathematics." Only 3 problems carry this tier. — [FAQ](https://epoch.ai/frontiermath/open-problems/about/faq); [Open Problems hub](https://epoch.ai/frontiermath/open-problems)

### Inferences
- The criterion in the prompt is the classical one behind Apéry's proof: if X = p/q, then q·L_n^m·(b_n − a_n X) is a nonzero integer, while condition 4 with L_n = e^{n+o(n)} forces it to 0. For Apéry's ζ(3) recurrence m = 3 and the linear form decays like (√2−1)^{4n} ≈ e^{−3.53n}, so ρ ≈ e^{−0.53} < 0.95 (this numerical remark is from memory of the classical proof, unverified here).
- Passing the verifier would be numerical evidence for n < 650, not a proof; Epoch says so in general terms. Conversely, Fauzan's proof was not checked by this verifier at all, because it contains no recurrence certificate.
- Under the FAQ's own rules, had Epoch judged the result "primarily due to human effort" the problem would have been removed rather than marked solved; marking it "human + AI" therefore reflects Epoch's belief that AI was instrumental.
- After the Solution update, the targets ζ(7), the Calegari–Dimitrov–Tang constant and γ are not reported as achieved anywhere I looked; DeepMind's formal-conjectures file still tags ζ(7), ζ(9), ζ(11) as "research open" (see Key question 3).

- The exact meaning of "the Calegari-Dimitrov-Tang constant" is not spelled out on the page (presumably L(2, χ_{−3}), whose irrationality Calegari, Dimitrov and Tang proved; that reading is my assumption).
- Whether any party submitted a recurrence certificate to math@epoch.ai is unknown.

## Key question 4: Other documented AI-related results on irrationality of zeta values and related constants, 2024–2026

### Takeaway
The only other AI-attributed irrationality results I could document are from OpenAI's 6 October 2026 release (Catalan's constant; irrationality exponent of π equal to 2), which Epoch cites as "solving another target" of the Apéry problem, and September 2026 follow-ups to Fauzan's method by Qian Tang and Si-Qi Liu that declare assistance from Claude Opus 5.5 and GPT-6-Astra. I found no ζ(5) or ζ(7) irrationality result attributed to Google DeepMind (AlphaProof/AlphaEvolve), Anthropic, xAI, Harmonic, Math Inc. or the Ramanujan Machine group.
