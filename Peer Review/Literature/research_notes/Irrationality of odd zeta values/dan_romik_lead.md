## 2. What exactly is in Romik's repository `danromik/zeta5-irrationality`

### Takeaway
It is a Lean 4.34.0 / Mathlib v4.34.0 development (70 files, about 29,000 lines, 11 commits between 23 and 25 September 2026) whose top-level theorem `Zeta5.zeta5_irrational : Irrational zeta5` has no hypotheses and no `sorry`, but depends on **one non-standard axiom, the prime number theorem θ(x) ~ x**; the README says in so many words that what Lean checks is "the implication: the prime number theorem implies that ζ(5) is irrational". The Lean code and documentation were written by Claude (Opus 5 / Opus 5.5) in multi-agent Claude Code workflows "directed by Dan Romik"; the repository also contains an AI-written referee-style audit of Fauzan's preprint that identifies one unproved load-bearing inequality.
